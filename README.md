# MIP_Lab1_exercitii
Lab1 exercises in order 
Realizati o aplicatie in care un text se muta in diverse pozitii in functie de butonul apasat
Realizati o aplicatie in care un text se muta in alta pozitie cand trecem mouse-ul peste el
Realizati o aplicatie care muta fereastra curenta in alta pozitie cand trecem mouse-ul peste un element din form (text, buton etc)
Realizati o aplicatie in care un buton isi schimba textul la apasarea altui buton
Realizati o aplicatie in care un buton isi schimba BackColor la apasarea altui buton(Simulare Start Stop cu afisare rosu verde pe un alt buton)
Realizati o aplicatie in care un text se plaseaza sus stanga sau jos stanga in functie de butonul apasat (sus jos)
Realizati o aplicatie in care un text se se afiseaza in diverse formate si culori in functie de butonul apasat
Realizati o aplicatie grafica pentru a desena un dreptunghi si diagonalele
Realizati o aplicatie grafica in care folositi un timer si un obiect random pentru a desena figuri aleatoare pe ecran
